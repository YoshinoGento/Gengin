# 害虫の表示と駆除反応

更新日: 2026-11-10。**実装・自動テスト・Releaseビルド済み。通常農場で印・虫・対象移動・駆除・保護範囲を確認。聞こえ方は未確認。**

## 目的と見え方

通知の文章だけでなく、畑を見て「対象の作物」「予防できる範囲」「駆除できたこと」を把握できるようにする。害虫の発生・拡散・品質減点のルールは変更しない。

| 状態 | 追加した表示 |
|---|---|
| 予兆 | 作物の上に黄色い立体の「！」を出し、ゆっくり上下させる |
| 被害中 | 「！」を橙色にし、小さなボクセルの虫2体を作物の周りで動かす |
| 虫よけを選択 | その植物と上下左右の土壌に緑色の角印を表示。斜めと水路には描かない |
| 駆除成功 | 対象の上から小さな粒6個を0.55秒広げ、0.34秒の短い音を鳴らす |

色だけに依存せず、予兆では印、被害中では印と虫で区別する。既存の文章による通知・対象への移動・駆除操作は残す。植物を選んだとき以外は保護範囲を描かないため、常時の情報量は増やさない。

これは表示データと通常呼出し経路を実装した状態であり、画面上の大きさや識別性の合格を意味しない。

## 通常プレイでの確認手順

1. `project/CG2_00_01.sln`を開き、起動プロジェクトを`CG2_00_01`、構成を`Release / x64`にする。`DirectXTex`はライブラリなので起動対象にしない。
2. 30日間の大会で作物を育てる。新規大会の最初の予兆は6日目。全対象が虫よけで保護されている場合や、未成熟の対象作物がない場合は発生しない。
3. 通知の「害虫の畑へ」で対象を選び、「！」が作物の上に表示されることを確認する。
4. 被害の表示を見る場合は駆除せずに翌日へ進める。虫が表示されることを確認した後、通知の駆除ボタン、または既存の`K`キー操作で駆除する。
5. 虫と印が消え、短い粒の演出が出ることを確認する。既に受けた品質減点は戻らない。
6. 虫よけ植物を選択して保護範囲を確認する。行の端から反対側へ印が回り込まないこと、水路上には出ないことを確認する。

元の保存を確認に使う場合は上書きせず別スロットを使う。今回はセーブファイルや提出ZIPを変更していない。フリー農業では害虫が無効なので、今回の表示も出さない。既存Debugテストには接続しておらず、新しいDebug画面も追加していない。

## 責務と処理順

1. UIが既存の駆除要求を通知する。
2. `FarmRuntimeController`が選択・状態を確認し、既存の`FarmPestSystem::Cure`を呼ぶ。ゲーム状態を変更するのは従来のSystem。
3. 駆除が成功した場合だけ、履歴とDirtyを更新し、表示Systemと音Systemへ成功を通知する。
4. `GamePlaySessionSystem`が実時間で表示Systemを更新する。
5. `FarmRenderer`が読み取り専用の部品データを既存のObject3dプールで描画する。

| 対象 | 所有するもの・役割 |
|---|---|
| `FarmPestVisualSystem` | Session所有。最大3件の駆除演出と経過時間を所有し、現在のGridから表示データを作る |
| `FarmPestMeshLayout` | 状態を変えない部品生成。作物の上端・土壌の平らな部分を基準に配置する |
| `FarmPestAudioSystem` | 専用のClipと最大1つのVoiceを所有。借用するFramework AudioはこのSystemより長生きする |
| `FarmRenderer` | 表示部品を既存の描画経路へ渡す。発生・被害・駆除の判定は行わない |

Game/SceneやUIに被害ルールを追加していない。既存の大きなController/Session全体の分割は今回行っていない。

## 保存・音・安全性

- 演出状態は保存しない。schema24と既存セーブの互換処理は変更しない。
- ロード・新規作成・拡張・Undo/Redo・タイムラインで古い駆除演出を破棄する。Gridの世代、作物、土地の高さも照合する。
- 害虫が消えたことを毎フレーム監視して音を鳴らす方式ではない。ロードや収穫を駆除成功と誤認しない。
- 音は外部サンプルを使わず合成した約16KBのWAV。生成スクリプトとSHA-256を含むmanifestを同梱する。
- 音量は既存の「審査演出」設定（タイトル側は「審査音」）と共用する。独立した新スライダーは追加しない。内部ゲインは設定値0〜100%に0.18を掛ける。既定40%なら0.072。
- 同時再生は1Voiceまで。0%では再生しない。メニュー・ショップ・フォーカス喪失等で停止し、終了時に自分のClip/Voiceだけを解放する。音源が読めなくても駆除処理は成立する。
- 配列容量、無効なマス、非有限の時刻、世代不一致を検査する。Grid全体のコピーや演出用の毎フレーム動的確保は増やさない。

## 描画負荷と限界

- 害虫3か所で最大30部品、選択した保護範囲で40部品、駆除3か所で18部品。追加部品の上限は合計88。
- 既存の箱モデルと白テクスチャを使う。新しいRender Pass・Shader・Descriptor・Barrier・Fence管理は追加しない。
- 虫本体はLightingとShadowに参加する。印・範囲・粒はUnlitでShadow対象外。透過ソートを必要とする粒は使わない。
- Object3dは既存プールを保持して再利用する。ただし初回の部品増加時には追加のObject/Constant Buffer確保があり、最大88部品分のDrawCallと、虫のShadow描画も増える。
- Instancingは未導入。上限を設けたことと、十分軽いことは別。CPU/GPU時間・VRAM使用量は実測していない。
- 量と演出時間の上限は`constexpr`、形の比率は部品生成ファイルへ集約した。JSONでの見た目調整は今回追加していない。
