# 通常農場の雨粒・雨音・明るさ

2026-11-10 / 実装・自動テスト・Release x64ビルド済み。通常農場の雨粒・取水停止・メニュー往復を実画面で確認。主観的な音量確認は未実施。

## 通常プレイで起きること

- 新規30日大会の8・18・28日目に雨を表示する。前日の予報では少し曇る。日程・土壌給水・品質・通知停止のルールは変更しない。
- 雨粒はワールド空間を上から下へ落ち、地面や作物の奥にある部分はDepth Testで隠れる。HUDより先に描画するため、文字の手前には重ねない。
- 雨の濃さは最大2.4秒、空と地面の明るさは最大3.5秒で切り替える。雨天のDirectional Lightと草のExposureは晴天基準の70%まで下げる。元の光量へ繰り返し乗算しない。
- 雨音は雨の濃さに追従する。既存の音量設定の「環境音」で変更でき、0%なら停止する。雨が終わるとフェードして停止する。
- 時間を止めても、農場が表示されフォーカスがある間は雨の動きを続ける。1/2/4倍速でも雨粒自体の落下速度は変えない。
- 種屋・展示・審査結果・導入演出では雨を表示しない。フォーカス喪失、レイアウト一覧、画面遷移開始、終了時には雨音を停止する。農場に重なる設定画面では環境音の調整結果を聞ける。
- 旧ルールのセーブとフリー農業は従来どおり雨なし。新しいDebug画面は追加しない。

## 通常操作での確認手順

1. `project/CG2_00_01.sln`を開き、`CG2_00_01`をスタートアップにして`Release / x64`で起動する。
2. 元の農場を上書きせず、検証用に新規の30日大会を始める。天候なしの旧セーブやフリー農業では表示されない。
3. 通常のカレンダーの時間送りで予報・雨の日へ進める。他の通知で止まった場合は、その内容を確認して再開する。
4. 雨開始の通知で時間が止まっても雨粒が落ちること、徐々に曇ること、作物や地面に雨粒が透けないことを確認する。
5. 環境音の音量を0%と低い音量に変え、種屋の往復とタイトル帰還で音が残らないことを確認する。
6. 雨上がりまで進め、雨粒・雨音・明るさが滑らかに晴天へ戻ることを確認する。

上記は全体の確認手順。後述の限定した実機確認と、未確認の項目を区別する。

## 責務と更新順

| 担当 | 所有・処理 |
|---|---|
| `FarmWeatherSystem` | 日付・保存済みルールから天候を取得。既存のゲームルールを維持 |
| `FarmRainPresentationSystem` | 読み取った天候と実時間から雨・雲のフェード値を生成。農地や日付を変更しない |
| `FarmRainGeometry` / `FarmRainRenderer` | 固定上限の雨粒形状と専用GPU資源。表示だけを担当 |

| `FarmArrivalRenderer` | 既存の天球と草へ曇天の色・Exposureを適用 |
| `GamePlaySessionSystem` | 天候取得、各System更新、光量適用、描画順、遷移・終了を統括 |
| 既存音量UI / Controller | 入力通知と既存設定値の提供。雨のルールは持たない |

ゲーム更新後に天候を読み、実時間のフェードを更新して光・音へ渡す。Opaque描画後に雨を描画し、最後にHUDを描画する。雨の状態をセーブへ追加しない。

## 安全性・負荷

- 雨粒は最大384本、2304頂点、1 DrawCall。CPU側は固定容量のspanに書き込み、毎フレームの動的確保やGridコピーを行わない。落下位置は固定seed相当のHashから決める。
- 頂点Bufferは64,512bytes、Constant Bufferは256bytesの論理サイズ。Committed Resourceの割当粒度があるため、この合計を実VRAM使用量とは扱わない。GPU/CPU時間・実VRAMは未計測。
- Upload Bufferは`GENERIC_READ`、Depth Testは`LESS_EQUAL`、Depth Writeなし。既存の1枚のScene Render TargetとDepthを使用し、追加Descriptor・Texture・Shadow描画はない。
- 再書込・破棄は既存`DirectXCommon::PostDraw`の毎フレームFence待ちに依存する。将来Frames In Flight化する場合はBufferのフレーム別管理が必要。
- Rendererはコピー禁止。資源生成はローカルComPtrに保持して成功時に移し、失敗時は雨描画なしへ戻る。AudioはVoice停止後に専用Clipを解放する。
- 不正なindexを使わず、入力容量・有限値・ゼロ長カメラ軸・極端な経過時間を検査する。表示上限とフェード時間はconstexpr、色・形状の比率は表示クラス内の設定。JSONへの新規設定追加はない。
- 既存の大きいSession/Controllerは全面リファクタリングせず、追加の描画・音声・フェード処理を別クラスに分離した。DX12資源をUIへ持たせない。

## 素材

`Resources/farm/weather/audio/rain.wav`は24kHz・mono・16bit・6秒、288,044bytes。`tools/audio/generate_rain_audio.py`で生成したノイズと水滴状の短音を使うループ素材で、外部録音・配布素材は使用していない。再生成用seedとHashのmanifestを同梱する。雨粒には画像素材を追加しない。
