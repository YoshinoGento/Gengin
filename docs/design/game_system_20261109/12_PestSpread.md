# 害虫の隣接拡散 / 放置と予防を判断につなげる

更新日: 2026-11-10。**実装・自動テスト16スイート・Releaseビルド済み。実画面は未確認。**

## 採用したルール

- この版で新しく始める30日間の大会で有効。古いセーブには拡散を追加しない。フリー農業では害虫自体が無効。
- 最初の予兆は6・16・26日目。発生中のマスがない場合に、対象となる作物をマス番号順に探す。抽選は行わない。
- 予兆から2日経過した作物は、上下左右へ拡散できる。斜めには広がらず、高さの違いは判定しない。
- **農場全体で1日1マスまで、同時に3マスまで。** 発生中のマス番号順に、左・右・上・下の順序で候補を探す。
- 新しく対象になった作物は、その日は予兆のみ。翌日から品質が1日6点、最大18点下がる。新規対象から同じ日内に連鎖しない。
- 作物がないマス、収穫可能な作物、被害履歴のある作物、虫よけ植物で保護されたマスは、新しい発生・拡散の対象外。
- 発生後に虫よけ植物を置いても治療にはならない。虫取り網で1マスずつ駆除する。受けた品質減点は残る。
- 30日目を過ぎると新たな発生・拡散は行わない。既存の被害の上限処理は維持する。

例: 6日目に予兆、7日目に被害6点、8日目に被害12点と隣接1マスの予兆。8日目に増えたマスは被害0点から始まる。対象や保護範囲がなければ拡散しない。

元案の確率発生・無制限な拡散は採用していない。現状では対処する量を読みやすくするため、日数と上限を固定した。値はSystemの`constexpr`で管理し、30日通しプレイでの難易度調整は未実施。

## 通常プレイでの操作

1. 新しい30日間の大会を開始し、作物を隣接させて育てる。保存済み農場を試す場合は、元セーブを上書きせず別スロットを使う。
2. Releaseでは新しい予兆が出ると時間が止まる。上部の「害虫の畑へ（○マス）」で対象を選ぶ。
3. 選択中の作物に害虫がいれば、「駆除する（残り○マス）」でそのマスだけ駆除する。従来の`K`キーでも同じ選択・駆除ができる。
4. ほかに対象が残っていれば案内を継続する。選択中に害虫がいない場合は、残る対象へ案内する。
5. 拡散を見る場合は駆除せず時間を再開する。安全な時間送りは、害虫への対応中には開始できず、新しい予兆でも停止する。

専用Debug画面は追加していない。既存のDebug「害虫テスト」は従来の単発発生の検証用で、この拡散を再現する画面ではない。

## 責務・処理順

| 対象 | 責務 |
|---|---|
| `FarmPestSystem` | 発生・隣接判定・被害・個別駆除・全解除を実行 |
| `FarmPestSpreadState` / `FarmProgressionSystem` | ルールversionと処理済み日付を所有し、Snapshotに含める |
| `FarmSimulationStepSystem` | 通常更新と時間送りで共通の、成長・日付・害虫更新順序を使う |
| `FarmDocumentSystem` | schema24を検証し、不正な状態を反映前に拒否 |
| `FarmNextGoalSystem` | 選択中の被害マスを優先し、なければ残る対象を選ぶ |
| `FarmPestView` / `FarmRuntimeController` | 件数と対処を表示し、既存の選択・駆除要求へ接続 |

UIは拡散や品質変更を行わない。Game/Sceneへルールを移さない。通常更新と時間送りは同じSystemを通るため、倍速によって別の害虫処理へ分岐しない。

日付境界では、その日の新規発生・拡散対象を既存の発生集合から1件だけ決める。新規予兆を登録した後、各マスの発生日と現在日から被害日数を求め、処理済み日付を保存する。同じ日付を再処理しても、駆除や読込を挟んで同日中に別のマスを増やさない。

## 保存と互換性

- schema24に`pestSpread.version`と`pestSpread.lastProcessedDay`を追加。通常セーブとタイムラインの進行Snapshotに含める。
- schema23以前はversion0として読み込み、従来の最大1マス・6/16/26日発生を維持する。保存し直しても拡散版へ自動変更しない。
- 拡散版では、処理済み日付と農場の日付が一致し、発生数が3以下で、発生日・被害日数が整合することを確認する。
- 不正な型、未対応version、未来の発生、処理日付の不一致、4マス以上の発生等は、現在の農場を変更する前に拒否する。
- 虫よけ植物の保存はschema23で導入したものを維持。レイアウト保存version3には今回変更なし。
- 旧EXEはschema24を読めない。元のセーブ・提出ZIPは変更していない。

## 安全性と性能

- 隣接座標を範囲検査し、行端から反対側への回り込みを禁止。候補ポインターは呼出し内だけで使う。
- 拡散元は固定長3件。判定用のGridコピーや動的確保は追加せず、変更対象のTileだけをコピーする。
- 日送り処理はシーズン30日までに制限。極端な日付でも日数分の無制限ループや整数加算overflowを避ける。
- 新しいRender Pass・Descriptor・Barrier・Fence・3D害虫モデルは追加していない。UIは既存Sprite Atlasのラベル追加のみ。
- Atlasは593ラベル・3840×1892。DrawCall、CPU/GPU時間、VRAM使用量の実測はしていない。
