## 今回わかったこと

- 害虫は当初企画の主要システム。BugNetという名前はあるが、発生・被害・駆除のゲーム処理はない。
- 台風は当初企画にもある。ただし主要な完成済み仕様ではなく、調整可能な追加候補。雨・干ばつの詳細は今回の新しい提案として区別する。
- 農場ランクは画面へ1を渡している。大会のS～D評価と農場ランクは別物。
- 作物と高さの段階解放、段階別入賞点、大会の提出・結果はすでに存在する。作り直す対象ではない。
- 安全な時間送りはSystemとテストがあるが、通常ゲームからの呼出しが見つからない。1/2/4倍速とは別機能。
- 大事なのは機能数ではなく、**状態を見る → 対策を選ぶ → 育成結果が変わる → 次の判断につながる**こと。

## 学校の評価基準との関係

添付資料は、遊びを強化するシステムがReleaseで体験でき、エンジン機能だけに留まらないことを求めている。ステージ、成長、寄り道、収集、スコア、保存、オンライン等は良い例であり、全部を実装する指定ではない。

本作では「害虫への対処が育成品質と大会結果につながる」を第一候補にする。虫の表示だけ、乱数で点数が下がるだけ、Debugボタンだけでは完成扱いにしない。
