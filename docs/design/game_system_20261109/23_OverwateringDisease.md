# 水カビ（ゲーム内の過湿障害）

ニンジン・トマト・かぼちゃが生育中に、品種の適正帯を超える水分が連続した場合に発生する。暦上の雨や水路との距離だけで発病させない。雨単独の浸透上限65%は、いずれの作物でも適正上限以下。

| 状態 | 条件と操作 | プレイ画面 |
|---|---|---|
| 健康 | 予兆のない短い過湿は、適正以下に戻ると持ち越さない | 通常の葉と給水案内 |
| 予兆 | 過湿6ゲーム秒。取水を切って追加の水やりを控える | 黄みのある葉と取水案内 |
| 発病 | 継続26ゲーム秒。生育速度のみを水分に応じた速度の90%にする | 葉が淡く低くなり、株元に一度だけ白い綿毛が浮く。土には白い斑が残る |
| 回復中 | 取水を切って水分が下がり始めると悪化を停止。過湿を抜けると蓄積を解消し、最大約6ゲーム秒で健康に戻る | 黄緑の葉と回復表示。発病した株だけ、蓄積が減るにつれて土の白さが薄れる |

4倍速でも予兆から発病まで約5実秒。時間送りは未対処の予兆・発病で停止し、従来の過湿停止も維持する。成熟後は病状を進めず、収穫で消去。枯死、伝染、薬剤使用による品質減点・値下げはない。

通常の給水・雨の後に成長処理が進む。水分による生育速度と病気の係数を分け、病気係数を水分管理の品質点に二重適用しない。各株の蓄積、前回水分、発病・回復状態はセーブ形式26で保存する。25以前を読み込んだ直後は健康。過去の過湿履歴から病状を逆算しない。

**農業用品店の防カビ剤**：1本40G。購入しても自動では使わない。畑で生育中の株を選び、「この株に防カビ剤」を押すと、その1株に1本を使う。予兆には間に合うが、発病中・発病からの回復中・成熟後は使えない。予防中の重ね掛けも不可。使えないときは在庫を消費しない。

散布時に発病前の過湿の蓄積を解消し、20ゲーム秒のあいだ新たに蓄積させない。土の水分や水分過多による生育への影響は変わらない。時間停止中は残り時間を維持し、4倍速なら約5実秒。効果が切れても直ちに発病せず、その後の過湿が続いた分から判定する。成熟・収穫で効果は終わり、次の作物には引き継がない。セーブ形式27は所持本数と株ごとの残り時間を保存する。26以前は所持0本・予防なしで読み込む。

**通常の比較体験**：「システム体験 → 水と環境 → 雨・給水」。18日目、左右のトマトは同じ予兆から開始する。左だけ取水を切り、開けたままの右と比べる。成熟すると病状は固定され、収穫で跡が消える。

**演出の確認版**：若い右の株を発病約5ゲーム秒前から開始。左は取水を閉じてある。右に綿毛が出たら右も止水する。綿毛は約1.15実秒だけで、読み直しても再放出しない。過湿を抜けると跡は徐々に薄くなる。確認版は通常の成長・描画処理を使い、病状や経過時間を演出で書き換えない。
