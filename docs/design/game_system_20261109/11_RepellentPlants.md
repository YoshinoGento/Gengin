# 虫よけ植物 / 面積を使って作物を守る

更新日: 2026-11-10。**実装・自動テスト・Releaseビルド済み。通常メニューで設置・表示・保護範囲を確認。通しプレイの調整は残る。**

同日追記: [害虫の隣接拡散](12_PestSpread.md)を追加。虫よけ植物は拡散先も保護する。その後の再開支援導入により通常セーブの現行形式はschema25。以下のschema23・ビルド/検証結果は虫よけ植物を導入した時点の記録で、拡散版の確認結果はリンク先へ分ける。

## 目的と今回のルール

作物を植える面積と、害虫対策の手間を交換する選択を追加する。虫の駆除を毎回繰り返す以外の対策として、既存の害虫システムへ接続した。

- 無料で1マスに設置し、無料で撤去できる。植付け費用・成長待ちは今回入れない。
- 設置対象は作物や水路のない土。未耕作・耕作済み・旧形式の水やり済み状態に対応する。
- **上下左右1マス**の作物に、新しい害虫の予兆が出なくなる。斜めは対象外。高さの違いは判定しない。
- 発生済みの害虫や、すでに受けた品質の減点は消さない。発生中の害虫には従来の虫取り網を使う。
- 置いたマスは作物・水路・水源・堆肥に使えない。撤去後に通常利用へ戻る。
- フリー農業では害虫が無効のため、設置はできるが予防効果が必要ないことを表示する。
- 6・16・26日目の新規発生では、保護外の対象を既存の順序で探す。すべて保護されていれば発生しない。撤去しても過去の日付の発生をやり直さない。

元案の「範囲内でも1%で発生・距離2」は未採用。現在は抽選のない害虫システムに合わせ、範囲を理解しやすい距離1と確実な新規予防を採用した。生物学的な再現ではなくゲーム上のルール。無料・範囲・占有面積のバランスは通しプレイで調整する。

## 通常ゲームでの操作

1. 「農場メニュー」を開き、「水路・地形」のタブを選ぶ。
2. 「虫よけ植物」を開く。
3. 左の3×3マップ、または「前のマス」「次のマス」でマスを選ぶ。中央が選択中のマス。
4. 「設置後」の保護表示と右側の設置条件を確認し、設置する。
5. 設置済みのマスを選ぶと「撤去後」の保護表示に切り替わり、撤去できる。

これは通常メニューであり、専用Debug画面は追加していない。条件に合わないマスでは設置ボタンを無効にする。地面では緑の茎・葉と黄橙色の花を持つボクセル形状として表示する。

## 責務と処理順

| 対象 | 責務 |
|---|---|
| `FarmTile::repellentPlant` | 設置状態の保存。外部オブジェクトを所有しない |
| `FarmRepellentSystem` | 設置条件、設置・撤去、保護判定、表示用データの生成 |
| `FarmPestSystem` | 新規発生の対象から保護マスを除外。既存の被害更新は継続 |
| `FarmRepellentView` | 値を受け取って表示し、操作要求を通知するだけ |
| `FarmRuntimeController` / `GamePlaySessionSystem` | メニューと要求の経路、競合状態の拒否、関連Systemの呼出し |
| `FarmDocumentSystem` / `FarmLayoutSystem` | 検証済み状態の保存・復帰 |
| `FarmMeshLayout` / `FarmRenderer` | 地面の上面へ8個の固定形状を配置し、既存描画へ渡す |

要求の受信後は、画面状態・Gridのgeneration・選択マス・占有条件を再検証してから1マスだけ変更する。古い編集Undoが設置状態を上書きしないよう履歴と比較状態を区切り、水路を再構築、Dirtyを設定、タイムラインを再初期化する。Game/Sceneに新しい農業ルールは追加していない。

`FarmIrrigationPreviewSystem`も占有状態を比較し、開始後に虫よけ植物の設置・撤去が起きたプレビューは確定を拒否する。水路・水源を虫よけ植物へ重ねるプレビューも開始前に拒否する。高さ変更自体は既存ルールで可能。

## 保存と互換性

- 各マスの`repellentPlant`はschema23で導入し、現行schema25でも保持する。schema22以前は未設置として読み込む。新しい形式は旧EXEでは読めないため、新旧版で同じセーブを上書き共有しない。
- レイアウト保存はversion3。version1/2も読み込める。虫よけ植物と水路の同居、不正な型や作物との同居は読込時に拒否する。
- 設置・撤去では高さ・水分・栄養・取水設定を変更しない。通常の水分更新は継続する。
- 通常保存、レイアウト、拡張時のTileコピーに状態を含める。元のセーブと提出物は変更していない。

## 安全性・負荷

- 保護判定は自分と隣接4マスの最大5件。表示用データは9セル固定で、Grid全体のコピーや保持ポインターは不要。
- 無効index、行端の回り込み、古いgeneration、選択変更、二重要求、未初期化・矛盾状態を拒否する。
- ボクセルは1株8パーツ。30マスすべてに設置したCPU側の生成テストは240パーツ。地形用と植物用の容量を別に検査する。
- 既存のObject3d・マテリアル・影の経路を使用する。新しいRender Pass、Descriptor、Barrier、Fenceの方式は導入しない。
- 実描画のDrawCall、CPU/GPU時間、VRAM使用量は未計測。8パーツを1回で描けるという意味ではない。固定視点で表示を確認したが、全地形の接地・影・視認性は未確認。
