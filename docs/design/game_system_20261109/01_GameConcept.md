# 01 / ゲーム案を現在の形で整理

## このゲームで何をするか

**土地の高さと用水路を設計し、水分と養分を管理して野菜を育て、品評会で入賞を目指す3D農業ゲーム。**

見た目の変化だけでなく、「水を届けたが多すぎた」「水路を止めて適量に戻せた」など、自分の設計と管理が品質・大きさに返ってくることを中心にする。

## プレイヤーの基本ループ

```text
目標・使える作物を確認する
  → 土地の高さと水路を計画する
  → 変更をプレビューして確定する
  → 耕す・必要なら堆肥を混ぜる・種を植える
  → 水分と成長を見て給水を調節する
  → 収穫する
  → 売って次の種を買う / 良い作物を保護して大会へ出す
  → 結果と不足を確認し、次の農場設計へ戻る
```

害虫・天候は今後、この「育成中の判断」に加える案。毎日同じクリックを増やすのではなく、どの作物を守るか、どこへ植えるかを考える理由にする。

## 現在あるモード

| モード | 現在の意味 | 注意点 |
|---|---|---|
| フリー農業 | 日数・所持金による終了なし。初期300G、3作物の種各5個 | 無限資金ではない。大会の繰り返し開催はない |
| 30日大会 | 10・20・30日目に出品。最終結果まで進む | 期間終了と入賞は別。各回の合否は別Systemで判断 |
| 従来の体験版 | 所持金540Gを終了目標とする仕組み | 大会の入賞条件と混ぜない |

新規大会では段階解放が有効。旧セーブや途中のモード変更で既存の道具・作物を勝手に再ロックしない実装になっている。

## 新規大会の段階

| 期間 | 使用可能な正式作物 | 造成上限 | その期間の大会目標 |
|---|---|---|---|
| 1～10日 | ニンジン | H1 | 10日目65点 |
| 11～20日 | ニンジン、トマト | H2 | 20日目75点 |
| 21～30日 | 上記とかぼちゃ | H2 | 30日目85点 |

出品対象の収穫日は順に1～10日、11～20日、21～30日。プレイヤーが保管庫の作物を予約して提出する。自動で最良作物を提出する仕組みではない。

## 作物の違い

- ニンジン: 比較的早く育つ。序盤の資金回収と基本操作の理解に使う。
- トマト: 適量水分の幅が狭い設定。水管理を続けて品質を狙う。
- かぼちゃ: 比較的遅く育つ。養分と水管理で大きさを狙う。

現在はすべて1マス栽培・1回収穫で耕した土へ戻る。連続収穫や2×2占有は未実装。成長速度・価格等はゲーム上の調整値で、実際の農業の数値ではない。

## 評価の仕組み

品質は成熟度・水分管理・地形適性・養分から算出し、大きさは育成履歴の水分効率と養分充足から予測する。大会は品質60点＋相対サイズ40点。水を最後に一度かけるだけで、過去の管理不足すべてを帳消しにはできない。

3大会の合計から出すS～D評価、各大会の入賞、農場ランク、他の出品者との順位は別概念。現在は前二者があり、農場ランクの成長と他者との順位はない。

## 元案から変わった点

| 元案・古い記録 | 現在の扱い |
|---|---|
| 名称「水道農業」 | 現在は「水路農業」 |
| 最良の作物を自動提出 | 自分で予約し、確認して提出 |
| 最終大会に1～30日の最良作物 | 現行の最終対象期間は21～30日 |
| 作物解放は10日・20日前後の候補 | 新規大会は11日・21日で実装 |
| Day30で優勝 | 現行は基準点による入賞。他者順位・優勝判定は未実装 |
| 農場Rank4 | 目標案のまま。現在のHUDはRank1固定 |
| 通常の土にも水が溜まり洪水になる | 現在の貯水は水路・水源中心。地表の洪水とは違う |
| Undo/Redoは今作らない | 現在は造成等に存在する。将来の被害処理との整合が必要 |

## 今後も維持する方針

追加の主役は水と作物の判断。台風・虫・ランクを無関係なミニゲームとして並べない。旧セーブの権限、確定済み点数、既存の価格・栽培ルールは、仕様変更の承認と移行設計なしに書き換えない。
