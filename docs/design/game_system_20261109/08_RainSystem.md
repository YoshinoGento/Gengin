# 予報付きの雨と取水判断

2026-11-10 / 初回実装・自動テスト・Debug/Releaseビルド完了。実画面での比較操作は未確認。

## 今回のルール

- 新規30日大会の8・18・28日目が雨、前日が予報日。日付と保存済みのルール版から決まり、開き直しても変わらない。
- 雨は耕した土へ直接給水する。取水OFFでも雨は入る。水路の貯水・給水とは別に集計する。
- 有効な浸透量はシミュレーション1秒あたり水分1.8ポイント、雨だけで増やせる上限は65%。既に65%超でも雨が水を減らすことはない。現実の降水量(mm)や洪水の物理モデルではない。
- 水路からの取水は65%を超えて給水できる。既存の過湿履歴・生育・品質評価へ反映する。採点式は変更しない。
- 通常のReleaseプレイと安全な時間送りは予報開始・降り始め・雨上がりで停止し、確認後に再開する。Debugの独立テストも各境界で停止する。
- schema 19以前の旧セーブは雨なし。schema 20は`weatherVersion`を保存する。フリー農業も雨なし。モード変更だけで旧農場へ強制追加しない。
- 雨粒・空の暗さ・音の切替は未実装。現時点では天候表示と土壌・生育への作用が対象。

## Debug操作

1. `project/CG2_00_01.sln`を開き、`CG2_00_01`をスタートアップに設定して`Debug / x64`でF5。
2. エディターのウィンドウメニューから「雨・取水テスト」を開く。タイトルにいても利用できる。
3. 「3. 雨・取水の比較」で同条件の2組を初期化する。違いはAが取水OFF、BがONであること。
4. 「60更新だけ進める」または「自動で進める」を押す。水分・成長・雨と水路の累積給水・過湿時間・予想品質を比較する。
5. 停止中は取水と1/2/4倍を変更できる。ケースをもう一度押すとリセット。最大60シミュレーション秒で停止し、非表示・フォーカス喪失でも止まる。
6. 予報直前、降り始め直前、雨上がり直前、晴れ、旧セーブ相当のケースもある。境界で停止した後に再度進められる。

独立したテスト用農場なので、現在の農場や元のセーブは変更しない。累積給水は加えた量であり現在の水分量ではない。予想品質は品評会の合計得点とは別。

## 責務

| 処理 | 担当 |
|---|---|
| 予報・雨の日程を読む | `FarmWeatherSystem`。版付きconstexpr表。乱数・描画・農地変更なし |
| 土への雨入力と水路の水収支 | `FarmIrrigationSystem`。外部の雨と有限な水路水量を分ける |
| 共通更新 | `FarmSimulationStepSystem`。日跨ぎ分割、雨→水路→成長→日付。長いdeltaでも各Systemと日付が同じ時間だけ進む |
| 停止と再開 | `FarmTimeAdvanceSystem`、通常プレイのController |
| 比較状態とDebug要求検証 | `FarmWeatherPlaytestSystem`。独立した2組を所有、有限回の更新 |
| 表示と要求通知 | `FarmWeatherTestWindow`、`FarmWeatherView` |
| 保存と旧データ互換 | `FarmDocumentSystem`/`FarmProgressionSystem`。未知の版や不正なモードを状態変更前に拒否 |

## 確認状況

`tools/tests/run_farm_weather_test.cmd`成功。予報/開始/終了×1/2/4倍、時間送りの停止と再開、旧セーブ、保存復帰、不正値、雨の上限と水収支、Debug操作を検証した。

固定トマト比較（4倍、60秒）ではOFFが水分65%/予想品質90、ONが約100%/48。固定条件の再現結果であり、全作物のバランス保証ではない。

回帰テストはtime_advance、pest、runtime_view、irrigation_intake、care_history、season_balance、free_mode、crop_size_document、formal_crops、stage_progressionが成功。既存の162シーズン検証は従来条件の回帰確認であり、新しい雨を含む全シーズンのバランス検証ではない。保存テスト5本は最新schemaの期待値を20へ更新し、未知の版の拒否と旧版移行の検証を維持した。

Debug/ReleaseをフルRebuildし、いずれも警告0・エラー0。別コピーのDebugタイトル表示とメニュー表示位置まで確認したところで、ユーザーのEsc操作により画面操作を停止した。その後、Debugプロセスの終了コード0を確認。新しい比較ウィンドウ・Releaseの予報表示・通常終了操作の実画面確認は未完了。以前のメモリ破損が解消したとは判断しない。

新しいGPU資源・Descriptor・Barrier・Fence・描画パスは追加しない。既存UI atlasに4ラベルを追加。毎更新のGridコピーなし。既存Irrigationの作業vectorは容量再利用する。追加のCPU/GPU時間、長時間、別PC、初見の分かりやすさは未検証。
