水路の試験田

SuiroNogyo.exe を起動すると、試験田から始まります。本編の農場やセーブは使いません。
水際から鍬を引いて、中央の溜め池に水を届けてください。畑から池へ掘ることもできます。

左ドラッグ：溝を掘る。下の「土を寄せる」を選んだ場合は、掘ったマスから隣へ払って土手を作ります。
右ドラッグ：道具を選び直さず土を寄せる。同じマスにもう一度使うと、元の土の山を移します。
矢印または WASD：移動。Enter と方向キーで掘る。Space と方向キーで土を寄せる。
「やり直す」または R：同じ地形を乾いた状態に戻します。岩は掘れません。

遊び比べる例：
・中央の真上から下へ掘り、くぼ地の水と溜め池の水を見比べる。
・そのまま、漏れている溝からくぼ地側へ土を払う。
・やり直して西岸からまっすぐ引く。今度は土手なしでどこまで届くだろう？
