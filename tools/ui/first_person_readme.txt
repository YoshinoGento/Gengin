水路農業　畑を歩く版

WASDで歩く。マウスで見回す。画面中央の照準が緑なら、今の道具を使えます。
左クリックで作業。ホイールまたは数字で持ち替えます。
1 鍬 / 2 種 / 3 じょうろ / 4 収穫かご。右クリックで種袋を持ち、もう一度押すと種類が変わります。
キーボードだけで遊ぶ場合は、矢印で視線、Enterで作業、Qで種の切替。

草地を耕して種をまき、芽に水をやります。作物が育ったら収穫かごに持ち替えて収穫。
熟したニンジンはクリックでそのまま収穫。左ボタン（またはEnter）を押し続けると葉をつかみ、離すと抜けます。途中で別のマスに照準を移すと手を離します。
F6 または Esc で通常の畑画面へ。F6 でもう一度畑に入れます。ホイール押し込みでも切り替えられます。
このフォルダーの農場は従来の見下ろし版とは別です。元の農場データをコピーする必要はありません。
