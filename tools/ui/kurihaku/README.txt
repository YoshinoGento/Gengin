水路農業

ZIPを展開し、このフォルダの SuiroNogyo.exe を起動してください。
Windows x64 / Direct3D 12 対応環境用。Resources と Settings は移動しないでください。

大会初日から野菜を育て、品評会への出品・入賞を目指します。
「畑へ」を選んだら、まず畑を１マス選び、下のクワと右下の作業ボタンで耕してください。
種は右の店で購入します。畑に植え、じょうろか水路で水を届けます。
畑の水分と画面上の「次」の案内を見て、実ったら収穫してください。
中断・再開は農場メニューの「セーブ・ロード」から行えます。

実装の確認は Source 内の project/CG2_00_01.sln（Visual Studio、Release / x64）から。
