水路農業 ｜ パーティクルエフェクト

ZIPをすべて展開してから SuiroNogyo.exe を起動してください。
Windows 10/11 64bit、DirectX 12 対応GPUが必要です。
「はじめる」の次はもう畑です。青い水源の隣、枠の中の土をクリックすると水路がつながります。
Enterでも掘れます。「今は掘らずに遊ぶ」または Esc でそのまま農作業に進めます。

・空き地を鍬で耕すと、刃が当たった瞬間に土塊と土ぼこりが跳ねます。
・耕した畑で種袋を使うと種が落ち、土がかぶります。じょうろで水をかけると土が濡れます。
・実っているニンジン、トマト、かぼちゃを収穫道具で選ぶと、収穫物が木箱に入ります。
・水路の続きを作るときは水路編集を開き、空きマスを選んで水路を仮置きし、確定します。
・土・作物・通水した水面をマウスでなぞると、土ぼこり・葉・波紋が反応します。

マウス：畑を左クリックして作業。ホイールで作業具を変更。
畑の上で右クリックすると種袋に切り替わり、ホイールで品種を変更。再度右クリックで元の道具に戻ります。
キーボード：矢印で畑を選択、Q/Eで道具を変更、Enterで作業。Cで種を選択。
タイトルまたは農場メニューの音量設定で、水音と効果音を調整できます。
畑の「操作」または H で操作ガイド。マウス、キーボード、併用、パッドのタブがあります。
パッドは Back でガイド、上下で項目を選び、B で戻ります。通常の農作業はマウスかキーボードを使います。
水分・成長率などを調べるときは「詳細表示」。Tabでも表示を切り替えられます。
