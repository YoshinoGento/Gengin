水路農業 / ゲームシステム体験版

Windows 10/11 64bit、DirectX 12対応GPUが必要です。
ZIPをすべて展開してから、フォルダ内の SuiroNogyo.exe を起動してください。
EXEだけを移動せず、Resources・Settings・DLLを同じフォルダに置いてください。
この専用版ではタイトルの後、畑に入る前に体験項目を選びます。

分類 → 試す項目 → この体験を始める → 確認、の順に選びます。
選んだ項目の右側に、できること・最初の操作・注目する変化を短く表示します。
畑に入った後は通常の道具や農場メニューを使います。
別の項目を試すときは、必要な進行を保存してタイトルに戻ってください。

栽培と売買: 種まき、収穫、土づくり、売却と保護
水と環境: 水路と高低差、雨、害虫駆除、防虫と拡散
大会と成長: 時間送り、品評会、結果と講評、農地拡張
記録と支援: 作物図鑑、生育比較、種の救済、セーブとロード
大会・クリア: 初日から開始、最終出品、目標点未満、未出品の終了
システム体験の下部から音量設定・保存画面にも移れます。

通常の栽培体験はフリーモードです。初期農場は配布版によって異なります。
雨・害虫などの体験は大会ルール専用です。選択画面で区別しています。
台風など未実装のシステムは含みません。

切替時に失われるのは現在の未保存の変更です。
保存済みの農場と、配布した体験用データには上書きしません。
残したい体験は保存画面で新しい名前を付けて保存してください。
終了後に自動で体験の続きを保存する仕組みではありません。

このフォルダは通常の制作セーブや過去の提出物と独立しています。
大会は「大会を初日から始める」から準備できます。
１日目・３００Ｇから栽培し、１０日目・２０日目・３０日目に出品します。
最終大会で８５点以上を取るとゲームクリアです。
クリア直前を試すには「大会・クリア」で最終出品の項目を選び、開始を確定します。
大会当日の案内が出たら「出品画面へ（停止を維持）」を選び、予約済み作物を提出します。
審査演出の後、結果・農場確認・再挑戦へ進めます。
展示用作物は準備済みですが、提出と審査は通常プレイと同じ処理です。
２０項目の体験データを同梱しています。
別PC・GPUでの動作と長時間プレイは未確認です。
