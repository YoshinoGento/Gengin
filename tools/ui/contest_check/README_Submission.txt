水路農業 / 要素別コンテスト「クリア演出」提出版
2026-11-17 / Windows 64bit Release

【起動】
ZIPを右クリックし「すべて展開」してから、StartGame.cmd を起動してください。
タイトルで「はじめる」を選ぶと、クリア演出の選択画面が開きます。
EXEだけを移動せず、Resources・Settings・DLLなどを同じフォルダに置いてください。

【操作】
・16個の項目から、見たいセリフをマウスで選びます。
・野菜と成績が切り替わり、ドラムロール → クリア発表 → 紙吹雪と左右の掛け声 → 結果の順に進みます。
・「もう一度見る」で同じ演出を再生できます。
・「ほかのセリフを見る」で一覧に戻れます。
・「演出を省略」で結果へ進めます。
・結果の「品質」「大きさ」タブで採点の内訳を確認できます。
・音量はタイトル右上の「音設定」で調整できます。
・終了するときはウィンドウ右上の×を押してください。

【提出範囲】
今回はクリア演出だけを確認できる専用版です。栽培や出品の操作は不要です。
3種類の野菜（ニンジン・トマト・かぼちゃ）、16組・全32台詞の左右の掛け合いを収録しています。
展示用の育成記録を、通常と同じ品質・大きさ・採点処理で評価しています。
個人の農場セーブは含めていません。通常制作版や過去の提出物とは独立しています。

【実行環境】
Windows 10/11 64bit、DirectX 12対応GPUを対象としています。
ゲーム中の通信や音声生成環境のインストールは不要です。
読み間違いと間を調整した音声修正版です。Releaseビルドと音声・表示の自動テストを実施しています。
前版ではこのPCで起動・選択・演出を確認しましたが、この音声修正版の実ゲーム画面での再確認は未実施です。
別PC・GPUでの互換性や、会場での音量・聞き取りやすさは未確認です。
