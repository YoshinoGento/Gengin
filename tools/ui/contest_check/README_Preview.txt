水路農業 / 音声付きの掛け合い・クリア演出の確認版

【起動と確認】
1. Start_Check.cmd をダブルクリック。
2. タイトルの「はじめる」を選ぶ。
3. 「入賞」を選び、「演出を見る」を押す。
4. ドラムロール → 大会クリア発表と紙吹雪 → 左右の観客の掛け声 → 得点表示。
5. 「もう一度見る」で条件に合う別の掛け合いを確認。「デモメニューへ」で別の結果を選ぶ。

栽培・日数送り・出品操作は不要です。準備済みの成績を読み取って再生します。
通常版と同じRelease EXE・演出処理ですが、この版は農場を進めない確認専用です。
「入賞ならず」「未出場」も選べます。こちらでは大会クリア演出を出しません。

【見る箇所】
・約1秒のドラムロール中は「大会クリア」・入賞の勲章・紙吹雪を出さない。
・発表時に祝福音、クリア文字、勲章、紙吹雪が始まる。
・野菜の前後を紙吹雪が通り、着地してから薄く消える。
・1.7秒から左の観客が呼びかけ、話し終わった約0.32～0.40秒後に右が返す。
・野菜の種類・大きさ・品質・手入れの記録・満点に応じた16組の掛け合い。
・同じ実行中は直前と同じ組を避ける。結果の詳細を読む間は出さない。
・「鍋に入らないぞ！」→「鍋のほうを育ててこい！」の2台詞のみ、新しい叫ぶ演技の音声です。
・残り30台詞は従来の音源です。全32台詞の差し替えは未完了です。
・声が最後まで収まる表示時間を確保。吹き出しが現れてから声を出し、二人が同時に話さない。
・台詞ごとの実際の長さで字幕・返答・結果の時刻を決め、長い台詞でも途中で切らない。
・紙吹雪と掛け合いの終了後、同じ画面で得点を表示し、詳細タブを操作可能にする。
・「演出を省略」では音を止め、その結果画面にとどまる。
・品質・大きさの詳細から戻っても、クリア演出は勝手に再発しない。
・別ウィンドウへ移った間は演出と音が止まり、戻ると続きから再開する。
