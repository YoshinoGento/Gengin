水路農業 / クリア確認版

【起動】
Start_Check.cmd をダブルクリックしてください。
EXE・Resources・Settings・DLLをまとめて同じフォルダに置いてください。

【最短でクリアを確認】
1. タイトルからゲームを開始。
2. 「この農場でプレイする」を選ぶ。
3. 大会当日の案内で「出品画面へ（停止を維持）」を選ぶ。
4. 「予約した１個を提出」を選び、確認画面でも提出する。
5. 自動で短いドラムロール、続いて「大会クリア」と紙吹雪が始まり、同じ会場に得点が表示されます。追加の開始操作は不要です。
6. 「成績一覧へ」で総合ランクと3回分の成績を確認。

最初から30日目で、合格点を取れる作物を出品予約済みです。
栽培・購入・30日分の待機は不要。起動時点ではまだ未提出・未クリアです。
開始演出は画面のスキップ操作で省略できます。
出品が終わるまで、時間の再開は不要です。

【もう一度・別の結果を確認】
「システム体験」→「大会・クリア」で次を選び、開始・切替確認を行います。
・展示：最終出品・クリア …… 成功をもう一度
・展示：目標点未満 …… 同じ提出操作で不合格を確認
・展示：未出品で終了 …… 期限切れの終了を確認
・大会を初日から始める …… 通常の大会を最初から確認
結果画面から体験一覧に戻れない場合は「終了した農場を見る」から体験一覧へ進めます。

【確認する箇所】
・紙吹雪が野菜の手前と奥に広がり、横に揺れながら落ちること
・空中で一斉に消えず、床へ着地してから薄くなること
・最終回の合格だけ、提出直後にクリア演出が自動で始まること
・約1秒のドラムロール中はクリア文字・入賞の勲章・紙吹雪がまだ出ないこと
・祝福の後、同じ画面に得点・入賞ラインが表示されること
・演出を省略しても結果画面にとどまり、もう一度操作するまでは成績一覧に進まないこと
・「品質」「大きさ」の詳細から結果へ戻っても、演出が再発しないこと
・一覧から「詳しく見る」で再閲覧しても、クリア演出が繰り返されないこと
・成功、点数不足、未出品が違う結果になること
・結果画面から農場確認、タイトル、再挑戦を選べること
・文字が切れず、音と操作が正常なこと

【保存・検証範囲】
通常版と独立したフォルダです。制作セーブや過去の提出物を使用していません。
切替時は確認版の未保存変更が失われます。残す場合は先に別名保存してください。
毎回勝手に初期化する起動処理はありません。再確認はシステム体験から選んでください。
作物の準備データ以外は通常Releaseと同じルール・提出・審査処理です。
EXEと文字画像の整合性、初期データのコピーを検査しています。
今回のドラムロール版の検証記録は制作プロジェクトの docs/design/game_system_20261109/22_FinalClearCelebration.md を参照してください。
通常の出品から一覧までの導線は前版で確認済みですが、今回はその全操作や音の聴感を再検証していません。
他PC・GPU・DPIは未確認です。展示前に使用するPCで上の手順を確認してください。
Windows 10/11 64bit、DirectX 12対応GPUが必要です。
