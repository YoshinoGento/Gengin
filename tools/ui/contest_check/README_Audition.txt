水路農業 / 新しい掛け声音声 2台詞の確認版

【起動】
1. Start_Check.cmd をダブルクリック。
2. 「はじめる」→「入賞」→「演出を見る」。
3. ドラムロール→大会クリア→左右の掛け声→結果表示。

左「鍋に入らないぞ！」
右「鍋のほうを育ててこい！」

この版は「もう一度見る」で、同じ2台詞を繰り返し確認できます。
右は左が話し終わった約0.34秒後に返します。
声は吹き出しの出現後に始まり、言い終わるまで表示します。
「演出を省略」で音を止め、結果の画面へ進めます。
別ウィンドウへ切り替えた間は演出と音が一時停止します。
品質・大きさのタブや「入賞ならず」「未出場」も確認できます。

【今回の範囲】
新音声は上記2台詞だけです。残り30台詞は従来の音声で、次回対応予定です。
Qwen3-TTSで演技を指定した架空の観客の合成音声です。
実在人物の声まねや録音ではありません。
2台詞の試聴方向はユーザー確認済みですが、ゲーム内の音量バランスは別途確認してください。
生成済みWAVを同梱するため、プレイ時の通信や音声生成ソフトは不要です。
全台詞の音声と文字が揃った最終提出版ではなく、2台詞の確認用です。

【保存】
通常版とは独立したコピーです。栽培・出品操作は不要で、農場を進めません。
EXE・Resources・Settings・DLLを同じフォルダに置いてください。
Windows 10/11 64bit、DirectX 12対応GPUが必要です。
音声: Qwen3-TTS / VOICEVOX Nemo。
