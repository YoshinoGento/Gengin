水路農業：クリア演出展示版

Start_Check.cmd を起動し、タイトルの「はじめる」を選びます。
16個の項目から、見たいセリフを選ぶと演出が始まります。

ドラムロール → 大会クリア → 紙吹雪と左右の掛け声 → 結果

・選んだ台詞に合う野菜、育成記録、成績へ切り替わります。
・「もう一度見る」は同じ掛け合いを再生します。
・「ほかのセリフを見る」で一覧へ戻れます。
・Enter / Space / Esc で演出を省略できます。
・品質と大きさの内訳は、結果のタブから確認できます。
・展示用の育成記録を既存の採点処理で評価しています。
  プレイヤーの農場やセーブデータは変更しません。

左右の音声は承認済みの合成音声を基準に作成しています。
詳しい音声クレジットは Resources/farm/contest/audio/cheers/CREDITS.txt。
音声生成モデルや生成環境はこの配布物には含まれません。
