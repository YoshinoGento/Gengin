水路農業 / 審査演出の展示版

ZIPを右クリックして「すべて展開」し、展開先のフォルダを開いてください。
起動: StartExhibition.cmd（ダブルクリック）
タイトルの池をクリック -> 展示メニューの「審査を見る」
農作業や30日間の進行、出品操作は不要です。

最初は「入賞ならず」を選んであります。
「入賞」「未出品」も同じ画面で選べます。
結果は自動で閉じません。「品質」「大きさ」で詳しく確認できます。
「もう一度見る」で演出を再生し、「展示メニューへ」で別の結果を選べます。
基本操作はマウスのクリックだけでできます。
キーボード: Enterで開始、矢印キーで選択、Escapeで戻る。
演出途中のEnter/Escapeは結果表示だけを早送りします。

育成・収穫・審査Systemを通して作った展示専用記録です。
今回の来場者が育てた野菜の結果ではありません。
不合格45点、入賞98点、30日目の基準85点。未出品は採点なしです。
通常のゲームと同じ採点・野菜モデル・レーダー図を使っています。
モデルの重量はゲーム内換算値です。

このフォルダは通常版・過去の提出ZIPとは独立しています。
展示中に通常の農場データを書き換えたりリセットしたりはしません。
環境音・水音・審査音の音量はタイトルの音設定で調整できます。
展示PCで実際の聞こえ方をご確認ください。

フォルダ全体を使ってください。EXE単体では起動できません。
Windows 10/11（64bit）/ DirectX12対応GPUが必要です。別PCでの動作は未確認です。
終了はウィンドウ右上の×です。ZIP内から直接起動しないでください。
