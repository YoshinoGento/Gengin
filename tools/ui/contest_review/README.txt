水路農業 / 大会結果の確認版

これはローカルで演出を確認するための版です。提出用ZIPではありません。
02_failed.cmd で不合格例、01_passed.cmd で入賞例、03_missed.cmd で未出品例を起動します。
ケースを切り替える前に、確認版のゲームを閉じてください。本編と同じRelease実行ファイルです。
StartGame.cmd は現在選ばれているデータで起動します。
元の農場・セーブ・提出物とは別フォルダで動きます。

最初は「不合格になる野菜を予約した30日目」です。
タイトルから進み、開始演出の後、大会案内から予約品を提出してください。
野菜の比較 → 品質 → 大きさ → 得点 → 不合格と助言 → 最終結果を確認できます。

各ケースの起動ファイルは、この確認フォルダ内の読み込み先だけを切り替えます。
保存した農場や結果を削除せず、元データの値も書き換えません。
Judging Ready は審査直前、Season Result は結果確認用です。
ゲームを閉じて同じケースの起動ファイルを開けば、審査直前データから繰り返せます。
確認用の Judging Ready 自体をゲーム内で上書き保存すると、その変更は残ります。

01: 給水を調整した例          10日94点 / 20日96点 / 30日98点
02: 給水を開きっぱなしの例    10日62点 / 20日42点 / 30日45点
03: 最終大会に提出しなかった例 10日94点 / 20日96点 / 30日未出品
合格点は順に65 / 75 / 85点。最終大会の合否とシーズン総合ランクは別です。
未出品は0点の提出記録として扱いません。

購入・給水・栽培・収穫・予約・提出をゲームのSystemに実行させたデータです。
品質や得点を直接設定していません。ただし人の操作による通しプレイではありません。
重さはゲーム内の換算値で、現実の野菜の実測値ではありません。

「結果を保存して再挑戦」は確認後に結果を別保存して1日目へ戻ります。
保存に失敗した場合は、農場をリセットせず結果画面に残ります。
演出中の「結果を表示」は早送りだけで、同時に再挑戦は実行しません。

確認点:
・不合格の理由と、次に変える育て方が読み取れるか
・演出の間や音量が適切か
・クリック/Enterでの早送り、詳細へ戻る操作が迷わないか
・入賞、不合格、未出品が混同されないか

別PC・別GPU・ゲームパッド・実プレイ難度は、この確認版の作成だけでは保証しません。
