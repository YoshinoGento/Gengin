水路農業 / ゲームシステム展示版

起動
SuiroNogyoExhibition.exe を開き、試す項目を選びます。
StartExhibition.cmd からも同じメニューを開けます。
タイトルでクリック →「この農場でプレイする」。
通常版と同じ操作・成長・採点ルールです。Debug画面は使用しません。
展示の待ち時間を減らすため、途中まで準備した農場から始めます。

おすすめの流れ
01 水路と栽培: 作物のあるマスを選び、水分・成長を確認。
   水分が多いときは取水を止め、育った作物を収穫します。
02 害虫への対処: 警告のある作物を確認し、農作業メニューから害虫を駆除。
   駆除後に警告が消えることを確認します。
03 雨と取水: 雨粒・雨音と水分の変化を確認。
   水路の取水を止めても、雨による水分は増えます。
04 土地拡張: 農作業 → 農場ランク・土地拡張 → 拡張を購入。
   1800Gで25マスから30マスへ。作物・水路は残ります。
   取消ならお金も面積も変わりません。
05 品評会への出品: 10日目の出品候補を予約済みです。
   品評会への出品と、結果・品質・大きさを確認します。
06 栽培の再開支援: 農作業 → 栽培の再開支援。
   ニンジンの種を1個受け取り、栽培を再開できます。

繰り返し展示する場合
ゲームのウィンドウを閉じると、項目選択に戻ります。
同じ項目を選び直すと、準備済みの状態からもう一度始められます。
「前回の続き」は展示用フォルダ内の保存状態を使います。
続きたい場合は、ゲームの通常メニューから保存してください。
元の開発用セーブや提出済みZIPは読み書きしません。
Scenarios は初期データ、PreviousRuns はこの展示版の退避データです。
ゲームを起動したまま別の項目へ切り替えることはできません。

準備データについて
01/02/03/05: 本番のSystemを使う自動プレイから記録。
04: 同じ記録の21日目に、拡張前の作物確認用として追加で植えた農場。
06: 救済条件を再現するため資金・種を0にした専用農場。
短時間で機能を見るための例であり、初見の30日間プレイの実測ではありません。

動作環境と注意
Windows / DirectX 12対応GPU。ZIPはすべて展開してから起動してください。
別PC・別GPUでの動作は未確認です。
展示メニューはWindowsの.NET Framework 4.xを使用します。
SuiroNogyo.exe を直接起動すると、保存状態から通常起動します。
初回は同梱済みの「水路と栽培」の農場です。
