水路農業 / 2026年10月 月次提出・通常版

ZIPをすべて展開してから StartGame.cmd を開いてください。
Windows x64 / DirectX 12対応環境が必要です。別PC・別GPUでは未検証です。

タイトルの池をクリック、またはEnter / Spaceで農場選択へ進みます。
新規状態では「この農場でプレイする」で30日間の大会モードを開始します。
時間制限なく試す場合は、農場選択で「フリー農業モード」に切り替えてください。

畑を選び、下部の道具から耕す・水やり・種まき・収穫を行います。
最初は種を持っていません。種屋で種を購入して育ててください。
選択した畑の状態は左下、次にできる操作は右下に表示されます。
大会では10・20・30日目に審査します。結果・品質・大きさの画面で振り返れます。
農場メニューから保存・読み込みやタイトルへの移動ができます。

過去の個人セーブは含めていません。プレイ後のSettingsはこのフォルダ内に作られます。
これはゲームオーバー演出だけのデモ版ではなく、通常のゲームを収録したものです。
演出の短い紹介は別添の作品紹介動画でも確認できます。
素材と外部ライブラリの通知は CREDITS.txt、Licenses、Resources内のクレジットを参照してください。
